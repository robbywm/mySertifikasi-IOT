Aspek kritis unit ini adalah ketepatan dalam membuat program visual antarmuka berbasis web. Dashboard dinilai tepat apabila setiap widget menampilkan data yang benar dari pin yang benar.

## 1. Landasan Teori

"Program visual antarmuka berbasis web" pada unit ini adalah dashboard yang dibuka lewat browser untuk memantau dan mengendalikan perangkat. Pelatihan ini memakai platform Blynk IoT, sehingga dashboard dapat disusun dengan menyeret widget tanpa menulis kode web.

### 1.1. Platform Blynk IoT

<figure><img src="https://3210525233-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FOdmXmHPTecdtQ82RSbYz%2Fuploads%2FahQlIIWUXbEzHmytcQUl%2Funknown.png?alt=media&amp;token=4748810a-91a9-47c5-b586-504a2b152749" alt=""><figcaption></figcaption></figure>

Blynk IoT adalah platform cloud untuk menghubungkan perangkat ke internet, menyimpan datanya, dan menampilkannya pada dashboard web maupun aplikasi smartphone (iOS dan Android). Server, database, dan antarmuka sudah disediakan oleh Blynk. Pengembang cukup menyiapkan firmware dan menyusun tampilan dashboard.

Dengan Blynk, pengguna dapat melihat data sensor secara real-time, membuka riwayat data, mengendalikan aktuator dari jarak jauh, dan menerima notifikasi. Hak akses setiap pengguna diatur lewat peran (*roles*) dan izin (*permissions*). Untuk produk komersial, Blynk juga menawarkan layanan *white label*, yaitu aplikasi dengan nama, logo, dan warna milik perusahaan pembuat perangkat.

### 1.2. Paket langganan

Fitur Blynk dibagi ke dalam beberapa paket: paket gratis ditujukan untuk belajar dan prototyping, sedangkan paket berbayar ditujukan untuk produk komersial. Setiap paket membatasi jumlah device, jumlah template, frekuensi kirim data, dan lama penyimpanan riwayat data.

{% hint style="warning" %}
**Perhatian.** Batas paket gratis berubah dari waktu ke waktu. Periksa halaman harga Blynk sebelum pelatihan dimulai. Pastikan paket yang dipakai menampung enam datastream dan seluruh widget pada bab ini.
{% endhint %}

### 1.3. Empat istilah yang wajib dipahami

Agar perangkat dapat berkomunikasi dengan Blynk, empat hal berikut disiapkan secara berurutan.

**Template**

**Datastream**

Datastream adalah saluran data antara mikrokontroler dan cloud, dan pada pelatihan ini seluruhnya berjenis *virtual pin* (V0, V1, dan seterusnya). Setiap datastream memiliki tipe data, dan tipe yang keliru membuat nilai tampil salah atau terpotong.

| Tipe data | Isi | Dipakai untuk |
| --- | --- | --- |
| Integer | Bilangan bulat | Status tombol atau LED (0 atau 1), nilai ADC potensiometer (0 sampai 1023) |
| Double | Bilangan desimal | Suhu (misalnya 25,4 °C), kelembapan, tekanan udara |
| String | Teks | Pesan status, misalnya "Sistem Normal" |

### 1.4. Alur data

Arah aliran data menentukan fungsi yang dipakai di firmware.

| Arah | Contoh | Fungsi di firmware |
| --- | --- | --- |
| Perangkat ke dashboard | Nilai suhu tampil di Gauge | `Blynk.virtualWrite(V0, suhu)` |
| Dashboard ke perangkat | Switch menyalakan LED | `BLYNK_WRITE(V3) { ... }` |

### Praktik 1: Uji Konektivitas Awal

Program ini hanya menghubungkan ESP8266 ke Wi-Fi dan ke Blynk Cloud, tanpa logika lain. Program serupa tersedia di Arduino IDE melalui **File > Examples > Blynk > Boards_WiFi > ESP8266_Standalone**.

Program: [`8.Uji_Konektivitas_Awal`](https://github.com/robbywm/mySertifikasi-IOT/tree/main/8.Uji_Konektivitas_Awal)

Kode lengkap juga tersedia di GitHub lewat tautan di atas.

```cpp
// --- KREDENSIAL BLYNK ---
#define BLYNK_TEMPLATE_ID "TMPLxxxxxx"
#define BLYNK_TEMPLATE_NAME "MySertifikasi"
#define BLYNK_AUTH_TOKEN "xxxxxxxxxxxxxxxxxxxxxxxxxxx"
#define BLYNK_PRINT Serial

#include <ESP8266WiFi.h>
#include <BlynkSimpleEsp8266.h>

char ssid[] = "NAMA_WIFI";
char pass[] = "SANDI_WIFI";

void setup() {
  Serial.begin(9600);
  Serial.println("Memulai uji koneksi ke Blynk Cloud...");
  
  // Fungsi ini akan melakukan koneksi WiFi sekaligus otentikasi Blynk
  Blynk.begin(BLYNK_AUTH_TOKEN, ssid, pass);
}

void loop() {
  Blynk.run();
}
```


**Hasil yang diharapkan:** Serial Monitor menampilkan baris `Ready (ping: ...ms)`, dan status device di konsol Blynk berubah menjadi **Online**.

### Praktik 1.2: Analisis Jaringan

Program ini menambahkan pembacaan kekuatan sinyal Wi-Fi atau RSSI (*Received Signal Strength Indicator*) setiap 5 detik. Catat dua angka untuk laporan: nilai ping pada baris `Ready (ping: ...ms)` dan nilai RSSI.

Program: [`9.Analisis_Jaringan`](https://github.com/robbywm/mySertifikasi-IOT/tree/main/9.Analisis_Jaringan)

Kode lengkap juga tersedia di GitHub lewat tautan di atas.

```cpp
// --- KREDENSIAL BLYNK ---
#define BLYNK_TEMPLATE_ID "TMPLxxxxxx"
#define BLYNK_TEMPLATE_NAME "MySertifikasi"
#define BLYNK_AUTH_TOKEN "xxxxxxxxxxxxxxxxxxxxxxxxxxx"
#define BLYNK_PRINT Serial

#include <ESP8266WiFi.h>
#include <BlynkSimpleEsp8266.h>

char ssid[] = "NAMA_WIFI";
char pass[] = "SANDI_WIFI";

BlynkTimer timer;

// Fungsi untuk menguji dan menampilkan status jaringan secara berkala
void cekKoneksiJaringan() {
  // Menampilkan kekuatan sinyal WiFi (RSSI)
  long rssi = WiFi.RSSI();
  Serial.print("Kekuatan Sinyal WiFi (RSSI): ");
  Serial.print(rssi);
  Serial.println(" dBm");

  Serial.println("-----------------------------------");
}

void setup() {
  Serial.begin(9600);
  Serial.println();
  Serial.println("Memulai uji koneksi ke jaringan WiFi dan Blynk Cloud...");
  
  Blynk.begin(BLYNK_AUTH_TOKEN, ssid, pass);

  // Menampilkan detail jaringan setelah terhubung
  Serial.println("===================================");
  Serial.print("Terhubung ke WiFi: ");
  Serial.println(WiFi.SSID());
  Serial.print("Alamat IP Perangkat: ");
  Serial.println(WiFi.localIP());
  Serial.println("Silakan catat nilai 'ping' di atas untuk analisis latency komunikasi data.");
  Serial.println("===================================");

  // Timer untuk cek kekuatan sinyal jaringan tiap 5 detik
  timer.setInterval(5000L, cekKoneksiJaringan);
}

void loop() {
  Blynk.run();
  timer.run();
}
```


Cara membaca nilai RSSI:

| RSSI | Kualitas sinyal |
| --- | --- |
| Lebih dari -60 dBm | Sangat baik |
| -60 sampai -70 dBm | Baik |
| -70 sampai -80 dBm | Lemah, koneksi mulai sering putus |
| Kurang dari -80 dBm | Buruk, pindahkan perangkat atau dekatkan ke router |

### Praktik 2: Pengendalian Output Digital

Perangkat menerima perintah dari Switch di dashboard (V3) untuk menyalakan dan mematikan LED status di pin D4, melalui fungsi `BLYNK_WRITE(V3)` yang dipanggil setiap kali nilai V3 berubah.

Program: [`10.Pengendalian_Output_Digital`](https://github.com/robbywm/mySertifikasi-IOT/tree/main/10.Pengendalian_Output_Digital)

Kode lengkap juga tersedia di GitHub lewat tautan di atas.

```cpp
// --- KREDENSIAL BLYNK ---
#define BLYNK_TEMPLATE_ID "TMPLxxxxxx"
#define BLYNK_TEMPLATE_NAME "MySertifikasi"
#define BLYNK_AUTH_TOKEN "xxxxxxxxxxxxxxxxxxxxxxxxxxx"
#define BLYNK_PRINT Serial

#include <ESP8266WiFi.h>
#include <BlynkSimpleEsp8266.h>

char ssid[] = "NAMA_WIFI";
char pass[] = "SANDI_WIFI";

#define PIN_LED D4 // Status LED pada KasgarIoT Shield (Active LOW)

// Fungsi ini dieksekusi saat ada perubahan status pada Switch di Web Dashboard (V3)
BLYNK_WRITE(V3) {
  int statusSwitch = param.asInt(); 
  
  // Karena D4 bersifat Active LOW, logika dari Switch dibalik menggunakan '!'
  // statusSwitch = 1 (ON) akan menjadi LOW (0) pada pin fisik sehingga LED menyala
  digitalWrite(PIN_LED, !statusSwitch); 
  
  if(statusSwitch == 1) {
    Serial.println("Instruksi Diterima: LED NYALA");
  } else {
    Serial.println("Instruksi Diterima: LED MATI");
  }
}

void setup() {
  Serial.begin(9600);
  pinMode(PIN_LED, OUTPUT);
  digitalWrite(PIN_LED, HIGH); // Kondisi awal mati (HIGH untuk Active LOW)
  
  Serial.println("Menghubungkan ke Blynk Cloud...");
  Blynk.begin(BLYNK_AUTH_TOKEN, ssid, pass);
}

void loop() {
  Blynk.run();
}
```


**Hasil yang diharapkan:** LED status menyala ketika Switch digeser ke ON dan padam ketika digeser ke OFF.

### Praktik 3: Pemantauan Input Digital

Perangkat mengirim status tombol D3 ke datastream V4 setiap 500 ms. Pengiriman diatur oleh `BlynkTimer`, sehingga `loop()` tidak pernah terhenti.

Program: [`11.Pemantauan_Input_Digital`](https://github.com/robbywm/mySertifikasi-IOT/tree/main/11.Pemantauan_Input_Digital)

Kode lengkap juga tersedia di GitHub lewat tautan di atas.

```cpp
// --- KREDENSIAL BLYNK ---
#define BLYNK_TEMPLATE_ID "TMPLxxxxxx"
#define BLYNK_TEMPLATE_NAME "MySertifikasi"
#define BLYNK_AUTH_TOKEN "xxxxxxxxxxxxxxxxxxxxxxxxxxx"
#define BLYNK_PRINT Serial

#include <ESP8266WiFi.h>
#include <BlynkSimpleEsp8266.h>

char ssid[] = "NAMA_WIFI";
char pass[] = "SANDI_WIFI";

#define PIN_TOMBOL D3 // User Button pada KasgarIoT (Active LOW)

BlynkTimer timer;

void kirimStatusTombol() {
  // Karena Active LOW, tombol ditekan = 0 (LOW), dilepas = 1 (HIGH). 
  // Kita balik logikanya dengan (!) agar di Dashboard bernilai 1 saat ditekan.
  int status = !digitalRead(PIN_TOMBOL); 
  
  Blynk.virtualWrite(V4, status);
  Serial.print("Status Tombol dikirim: ");
  Serial.println(status == 1 ? "DITEKAN" : "DILEPAS");
}

void setup() {
  Serial.begin(9600);
  pinMode(PIN_TOMBOL, INPUT_PULLUP);
  
  Blynk.begin(BLYNK_AUTH_TOKEN, ssid, pass);
  timer.setInterval(500L, kirimStatusTombol); // Alokasi timer interval
}

void loop() {
  Blynk.run();
  timer.run(); // Eksekusi timer
}
```


**Hasil yang diharapkan:** widget V4 menunjukkan 1 saat tombol ditekan dan 0 saat dilepas.

{% hint style="warning" %}
**Perhatian.** Jangan memakai `delay()` di dalam `loop()` pada program Blynk. Selama `delay()` berjalan, `Blynk.run()` tidak terpanggil dan koneksi ke cloud dapat terputus. Pakai `BlynkTimer` untuk pekerjaan berkala. Jangan pula mengirim data lebih sering dari yang dibutuhkan, karena Blynk membatasi jumlah pesan per detik.
{% endhint %}

### Praktik 4: Pemantauan Input Analog

Perangkat membaca potensiometer di A0 lewat ADC, lalu mengirim nilainya ke V5 setiap 1 detik.

### Praktik 5: Pemantauan Suhu dan Kelembapan (DHT22)

Perangkat membaca DHT22 di pin D5 setiap 2 detik, lalu mengirim suhu ke V0 dan kelembapan ke V1. Bila pembacaan gagal, data tidak dikirim sehingga dashboard tidak menampilkan nilai yang salah.

Program: [`13.Pemantauan_Suhu_Kelembapan`](https://github.com/robbywm/mySertifikasi-IOT/tree/main/13.Pemantauan_Suhu_Kelembapan)

Kode lengkap juga tersedia di GitHub lewat tautan di atas.

```cpp
// --- KREDENSIAL BLYNK ---
#define BLYNK_TEMPLATE_ID "TMPLxxxxxx"
#define BLYNK_TEMPLATE_NAME "MySertifikasi"
#define BLYNK_AUTH_TOKEN "xxxxxxxxxxxxxxxxxxxxxxxxxxx"
#define BLYNK_PRINT Serial

#include <ESP8266WiFi.h>
#include <BlynkSimpleEsp8266.h>
#include <DHT.h>

char ssid[] = "NAMA_WIFI";
char pass[] = "SANDI_WIFI";

// Konfigurasi Sensor DHT
#define DHTPIN D5
#define DHTTYPE DHT22
DHT dht(DHTPIN, DHTTYPE);

BlynkTimer timer;

void kirimDataDHT() {
  float suhu = dht.readTemperature();
  float kelembapan = dht.readHumidity();

  if (isnan(suhu) || isnan(kelembapan)) {
    Serial.println("Peringatan: Gagal mengakuisisi data dari DHT22");
    return;
  }

  Serial.print("Suhu: "); Serial.print(suhu); Serial.print(" C | ");
  Serial.print("Kelembapan: "); Serial.print(kelembapan); Serial.println(" %");

  Blynk.virtualWrite(V0, suhu);
  Blynk.virtualWrite(V1, kelembapan);
}

void setup() {
  Serial.begin(9600);
  
  dht.begin();
  Blynk.begin(BLYNK_AUTH_TOKEN, ssid, pass);
  
  timer.setInterval(2000L, kirimDataDHT); // Siklus pembacaan tiap 2 detik
}

void loop() {
  Blynk.run();
  timer.run();
}
```


**Hasil yang diharapkan:** Gauge V0 dan V1 terisi, dan Chart mulai menggambar garis suhu serta kelembapan.

### Praktik 6: Pemantauan Tekanan Udara (BMP280 via I2C)

Perangkat membaca tekanan udara dari BMP280 lewat I2C, lalu mengirimnya ke V2 setiap 2 detik. Jika sensor tidak terdeteksi, program menampilkan peringatan dan tidak mengirim data.

Program: [`14.Pemantauan_Tekanan_Udara`](https://github.com/robbywm/mySertifikasi-IOT/tree/main/14.Pemantauan_Tekanan_Udara)

Kode lengkap juga tersedia di GitHub lewat tautan di atas.

```cpp
// --- KREDENSIAL BLYNK ---
#define BLYNK_TEMPLATE_ID "TMPLxxxxxx"
#define BLYNK_TEMPLATE_NAME "MySertifikasi"
#define BLYNK_AUTH_TOKEN "xxxxxxxxxxxxxxxxxxxxxxxxxxx"
#define BLYNK_PRINT Serial

#include <ESP8266WiFi.h>
#include <BlynkSimpleEsp8266.h>
#include <Wire.h>
#include <Adafruit_BMP280.h>

char ssid[] = "NAMA_WIFI";
char pass[] = "SANDI_WIFI";

Adafruit_BMP280 bmp; // Menggunakan bus I2C bawaan (D1, D2)

BlynkTimer timer;
bool bmpSiap = false;

void kirimDataBMP() {
  if (!bmpSiap) return; // Sensor tidak terdeteksi, jangan kirim data palsu

  float tekanan = bmp.readPressure() / 100.0F;

  Serial.print("Tekanan Udara: "); Serial.print(tekanan); Serial.println(" hPa");

  Blynk.virtualWrite(V2, tekanan);
}

void setup() {
  Serial.begin(9600);
  
  // Alamat I2C BMP280 adalah 0x76 atau 0x77, tergantung pin SDO pada modul
  bmpSiap = bmp.begin(0x76) || bmp.begin(0x77);
  if (!bmpSiap) {
    Serial.println("Peringatan: Sensor BMP280 tidak terdeteksi (0x76/0x77). Data V2 tidak dikirim.");
  }

  Blynk.begin(BLYNK_AUTH_TOKEN, ssid, pass);
  timer.setInterval(2000L, kirimDataBMP); // Siklus pembacaan tiap 2 detik
}

void loop() {
  Blynk.run();
  timer.run();
}
```


**Hasil yang diharapkan:** Gauge V2 menampilkan tekanan udara dalam hPa.
