# Glosarium

Istilah teknologi pada modul ini sengaja dibiarkan dalam bahasa Inggris apabila bentuk itulah yang dipakai di lapangan, di dokumentasi, dan di menu software. Tabel berikut memuat artinya.

| Istilah | Arti |
| --- | --- |
| Access point | Pemancar Wi-Fi. Perangkat dapat berperan sebagai access point sementara saat provisioning. |
| Active LOW / Active HIGH | Komponen aktif ketika pin bernilai LOW (0 V) atau HIGH (3,3 V). |
| ADC | *Analog-to-Digital Converter*, pengubah tegangan menjadi angka. Pada ESP8266 hasilnya 0 sampai 1023. |
| Aktuator | Komponen yang melakukan aksi, misalnya LED, relay, atau motor. |
| Auth Token | Kode unik yang menjadi identitas dan kunci sebuah device di Blynk. |
| Baud rate | Kecepatan komunikasi serial, misalnya 9600 atau 115200. |
| Board | Papan rangkaian, misalnya Wemos D1 R2. |
| Bug | Kesalahan pada program. |
| Cloud | Server di internet yang menyimpan dan mengolah data perangkat. |
| Compile | Mengubah kode program menjadi berkas yang dapat dijalankan mikrokontroler. |
| Dashboard | Tampilan untuk memantau dan mengendalikan perangkat. |
| Datasheet | Dokumen spesifikasi resmi dari pabrikan komponen. |
| Datastream | Saluran data antara perangkat dan Blynk Cloud. |
| Debugging | Mencari dan memperbaiki kesalahan program. |
| Device | Perangkat IoT. |
| ESD | *Electrostatic discharge*, perpindahan listrik statis yang dapat merusak komponen. |
| Fallback | Tindakan mengembalikan perangkat ke keadaan berfungsi ketika pembaruan gagal. |
| Firmware | Program yang tersimpan dan berjalan di mikrokontroler. |
| Flash | Memori penyimpan program pada mikrokontroler. |
| GPIO | *General Purpose Input/Output*, pin serbaguna pada chip. |
| Hardcode | Menulis nilai, misalnya password, langsung di dalam kode program. |
| I2C | Protokol komunikasi dua kabel (SDA dan SCL) antara mikrokontroler dan komponen. |
| IDE | *Integrated Development Environment*, aplikasi untuk menulis dan meng-upload program. |
| KUK | Kriteria unjuk kerja, hasil terukur yang diperiksa asesor. |
| Latency | Jeda antara data dikirim dan diterima. |
| Library | Kumpulan kode siap pakai untuk keperluan tertentu. |
| mDNS | *Multicast DNS*, cara perangkat memperkenalkan namanya di jaringan lokal. |
| OTA | *Over The Air*, pemasangan firmware lewat jaringan tanpa kabel data. |
| Patch | Pembaruan firmware untuk menutup celah keamanan atau memperbaiki bug. |
| Ping | Waktu bolak-balik sebuah paket data ke server, dalam milidetik. |
| Provisioning | Proses memasukkan konfigurasi jaringan ke perangkat setelah firmware terpasang. |
| Pull-up | Resistor yang menahan pin pada nilai HIGH ketika tidak ada sinyal. |
| PWM | *Pulse Width Modulation*, cara mengatur daya rata-rata dengan menyalakan dan mematikan pin secara cepat. |
| QC | *Quality Control*, pemeriksaan kelayakan perangkat. |
| RSSI | *Received Signal Strength Indicator*, kekuatan sinyal Wi-Fi dalam dBm. |
| Sensor | Komponen yang mengubah besaran fisik menjadi sinyal listrik. |
| Serial Monitor | Jendela pada Arduino IDE untuk melihat data yang dikirim perangkat. |
| Shield | Papan ekspansi yang dipasang menumpuk di atas board. |
| Sketch | Sebutan untuk program pada Arduino IDE. |
| SLA | *Service Level Agreement*, tingkat layanan yang disepakati dengan pengguna. |
| SOP | *Standard Operating Procedure*, prosedur kerja baku. |
| Template | Cetak biru sebuah jenis perangkat di Blynk. |
| TLS | *Transport Layer Security*, protokol enkripsi koneksi. |
| Troubleshooting | Mencari penyebab masalah dan memperbaikinya. |
| TUK | Tempat Uji Kompetensi. |
| UI | *User Interface*, tampilan tempat pengguna berinteraksi dengan aplikasi. |
| Upload | Mengirim program dari laptop ke mikrokontroler. |
| Usability | Kemudahan dan keberfungsian komponen aplikasi saat dipakai. |
| UX | *User Experience*, pengalaman pengguna saat memakai aplikasi. |
| Virtual pin | Pin maya (V0, V1, dan seterusnya) yang menjadi alamat datastream di Blynk. |
| Widget | Komponen tampilan pada dashboard, misalnya Gauge, Switch, dan Chart. |
