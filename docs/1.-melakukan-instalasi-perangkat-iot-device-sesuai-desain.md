## 1. Landasan Teori

Pekerjaan instalasi dimulai dari perangkat di titik akhir jaringan, yang disebut *end device* atau *node*. Perangkat inilah yang berhubungan langsung dengan lingkungan fisik, misalnya mengukur suhu ruangan atau menyalakan lampu.

### 1.1. Arsitektur node IoT

Sebuah node IoT tersusun atas tiga blok.

* **Unit pemroses (mikrokontroler).** Menjalankan program dan menangani koneksi jaringan.
* **Unit masukan (sensor).** Mengubah besaran fisik, misalnya suhu atau tekanan, menjadi sinyal listrik yang dapat dibaca mikrokontroler.
* **Unit keluaran (aktuator).** Melakukan aksi berdasarkan perintah mikrokontroler, misalnya LED, relay, atau motor.

### 1.2. Wemos D1 R2

Mikrokontroler yang dipakai pada pelatihan ini adalah Wemos D1 R2, yaitu board dengan SoC (*System on a Chip*) ESP8266 yang sudah memiliki Wi-Fi di dalamnya. Tata letak pinnya menyerupai Arduino Uno, sehingga shield berukuran Uno dapat dipasang langsung di atasnya.

### 1.3. Shield plug-and-play

Kesalahan pengkabelan adalah penyebab kerusakan yang paling sering terjadi saat prototyping. Untuk menghindarinya, pelatihan ini memakai papan ekspansi **KasgarIoT Shield R1** yang dipasang menumpuk di atas Wemos D1 R2 tanpa kabel jumper. Di dalam shield sudah tersedia sensor DHT22 dan BMP280, potensiometer, tombol, LED status, dan LED RGB.

### 1.4. Desain, hasil uji lab, dan instalasi

Pada pekerjaan nyata, instalasi selalu mengacu pada tiga dokumen, yaitu desain perangkat, hasil uji di lab, dan rencana instalasi, yang di kelas ini disederhanakan seperti pada tabel berikut.

### 2.2. Wemos D1 R2 ESP8266

<figure><img src="https://3210525233-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FOdmXmHPTecdtQ82RSbYz%2Fuploads%2FFeeig9Ql0JHZ3ls7BRYg%2Funknown.png?alt=media&amp;token=2e2a6409-72a4-47b0-ab5a-9c2e4ce24bbb" alt=""><figcaption></figcaption></figure>

Wemos D1 R2 adalah *development board* berbasis chip ESP8266 yang dapat diprogram dengan Arduino IDE. Port micro USB pada board ini dipakai untuk catu daya sekaligus transfer program.

| Spesifikasi | Nilai |
| --- | --- |
| CPU | RISC 32-bit, 80 MHz |
| RAM | 64 KB *instruction* RAM dan 96 KB *data* RAM |
| Flash memory | 4 MB |
| Pin digital | 11 pin |
| Pin analog | 1 pin (A0) |
| Komunikasi | Serial (UART), I2C, SPI |
| Konektivitas | Wi-Fi 2,4 GHz |
| Tegangan masuk | 5 V lewat USB |
| Tegangan logika pin | 3,3 V |

{% hint style="warning" %}
**Perhatian.** Pin ESP8266 bekerja pada 3,3 V. Sensor atau modul 5 V yang dihubungkan langsung ke pin digital dapat merusak chip. Hal ini tidak menjadi masalah selama Anda hanya memakai KasgarIoT Shield, tetapi perlu diingat saat menambah komponen sendiri.
{% endhint %}

### 2.3. KasgarIoT Shield R1

<figure><img src="https://3210525233-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FOdmXmHPTecdtQ82RSbYz%2Fuploads%2FMkc8w3GTSP3tdg2n9GEz%2Funknown.png?alt=media&amp;token=a05c618b-06fd-4738-b0b9-7f4954fa87ff" alt=""><figcaption></figcaption></figure>

KasgarIoT Shield R1 dirancang khusus untuk Wemos D1 R2, dan dokumentasi resminya tersedia di [kasgariot-docs](https://kasgariot.gitbook.io/kasgariot-docs/).

<figure><img src="https://3210525233-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FOdmXmHPTecdtQ82RSbYz%2Fuploads%2FYPucybsfouSZbLQjfQDl%2Funknown.png?alt=media&amp;token=192fabdc-6243-42d2-a0a7-5ea4fc1fbea7" alt=""><figcaption></figcaption></figure>

Pemetaan pin pada tabel berikut adalah desain yang menjadi acuan seluruh bab. Label D0 sampai D8 tercetak di board, sedangkan nomor GPIO adalah nomor pin pada chip ESP8266 yang kadang muncul di dalam program.

| Komponen | Pin board | GPIO | Logika atau protokol |
| --- | --- | --- | --- |
| LED status | D4 | GPIO2 | Active LOW (menyala saat diberi LOW) |
| Sensor suhu dan kelembapan DHT22 | D5 | GPIO14 | Digital satu kabel |
| LED RGB merah | D7 | GPIO13 | Active HIGH |
| LED RGB biru | D6 | GPIO12 | Active HIGH |
| LED RGB hijau | D8 | GPIO15 | Active HIGH |
| Tombol USER | D3 | GPIO0 | Active LOW (bernilai 0 saat ditekan) |
| Potensiometer | A0 | ADC0 | Analog |
| Sensor tekanan BMP280 | D1 (SCL), D2 (SDA) | GPIO5, GPIO4 | I2C, alamat 0x76 |

{% hint style="info" %}
**Untuk pemula.** *Active LOW* berarti komponen aktif ketika pin bernilai LOW (0 V). LED status di D4 termasuk jenis ini, sehingga `digitalWrite(D4, LOW)` justru menyalakannya. *Active HIGH* adalah kebalikannya.
{% endhint %}

## 4. Langkah Kerja 2: Instalasi

### 4.1. Memasang perangkat keras

{% stepper %}
{% step %}
#### Siapkan meja kerja

Gelar alas antistatik dan pastikan meja bersih dari cairan, potongan kabel, serta serpihan logam. Bila tersedia, pakai gelang antistatik. Prosedur ini mengikuti SOP penanganan perangkat elektronika yang disebut pada batasan variabel SKKNI.
{% endstep %}

{% step %}
#### Periksa kondisi fisik

Amati Wemos D1 R2 dan shield. Pastikan tidak ada pin yang bengkok, komponen yang lepas, atau bekas terbakar. Catat kondisi awal ini pada laporan.
{% endstep %}

{% step %}
#### Pasang shield

Dalam keadaan kabel USB **belum** terhubung, sejajarkan seluruh pin shield dengan header Wemos D1 R2, lalu tekan merata sampai shield duduk rapat. Pin yang bergeser satu lubang dapat menyebabkan short circuit.
{% endstep %}

{% step %}
#### Beri catu daya

Hubungkan kabel micro USB ke laptop. LED power pada board harus menyala stabil. Sentuh permukaan chip secara singkat. Jika ada komponen yang terasa panas, cabut kabel saat itu juga dan periksa ulang pemasangan shield.
{% endstep %}
{% endstepper %}

### 4.3. Menginstal board ESP8266 pada Arduino IDE

<figure><img src="https://3210525233-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FOdmXmHPTecdtQ82RSbYz%2Fuploads%2Fn3k8yh55OOgNstxm3yUJ%2Funknown.png?alt=media&amp;token=541b3f0f-ea2c-4d0f-9133-d55ac16a1347" alt=""><figcaption></figcaption></figure>

1. Buka Arduino IDE.
2. Buka menu **File > Preferences**.
3. Pada kolom **Additional Boards Manager URLs**, masukkan alamat berikut.

```
https://arduino.esp8266.com/stable/package_esp8266com_index.json
```

4. Klik **OK**.
5. Buka menu **Tools > Board > Boards Manager**.
6. Ketik `esp8266` pada kolom pencarian, pilih paket **esp8266 by ESP8266 Community**, lalu klik **Install**. Pakai versi yang ditentukan instruktur supaya hasil satu kelas seragam.
7. Pilih board melalui **Tools > Board > ESP8266 Boards > LOLIN(WEMOS) D1 R2 & mini**.
8. Pilih port melalui **Tools > Port**.

## 6. Langkah Kerja 4: Troubleshooting Masalah Minor

SKKNI membatasi troubleshooting pada unit ini untuk kesalahan kecil yang dapat diperbaiki di lapangan, dan tabel berikut memuat masalah semacam itu yang paling sering muncul di kelas.

| Gejala | Kemungkinan penyebab | Penanganan |
| --- | --- | --- |
| Port COM tidak muncul | Driver CH340 belum terpasang, atau kabel hanya untuk mengisi daya | Instal ulang driver, ganti dengan kabel data, coba port USB lain |
| Upload gagal dengan pesan *Failed to connect* atau *Timed out* | Board atau port yang dipilih salah, atau Serial Monitor di aplikasi lain sedang memakai port | Periksa Tools > Board dan Tools > Port, tutup aplikasi lain yang membuka port |
| Program tidak berjalan setelah perangkat dinyalakan | Tombol USER (D3) tertekan saat perangkat mendapat daya | Lepaskan tombol, lalu tekan tombol RESET pada board |
| Serial Monitor menampilkan karakter acak | Baud rate tidak sama dengan `Serial.begin(...)` | Samakan baud rate (9600 atau 115200 sesuai program) |
| Board *esp8266* tidak ada di Boards Manager | Alamat pada Additional Boards Manager URLs salah ketik | Periksa ulang alamatnya, lalu buka kembali Boards Manager |
| Salah satu komponen terasa panas | Shield terpasang bergeser sehingga terjadi short circuit | Cabut daya saat itu juga, pasang ulang shield, ukur tegangan 3V3 |
| LED power redup atau berkedip | Arus dari port USB kurang | Pindah ke port USB lain atau pakai kabel yang lebih pendek |

{% hint style="warning" %}
**Perhatian.** Pin D3 (GPIO0), D4 (GPIO2), dan D8 (GPIO15) dibaca oleh ESP8266 saat mulai menyala untuk menentukan mode boot. Itulah sebabnya tombol di D3 tidak boleh ditekan ketika perangkat baru diberi daya.
{% endhint %}

Setiap masalah yang Anda alami, sekecil apa pun, dicatat pada laporan di Bagian 7. Jika masalah tidak teratasi dengan tabel di atas, laporkan kepada instruktur dan tuliskan sebagai ketidaksesuaian.
